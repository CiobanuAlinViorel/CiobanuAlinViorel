## 🤖 How I build

I use AI tools (**Claude Code, Codex, Cursor, Devin**) across the whole delivery cycle:

1. **Plan**: turn requirements into an AI-assisted implementation plan
2. **Implement**: build directly from that plan
3. **Verify**: AI reviews its own work, switching models and contexts to catch what a
   single model misses

I stay hands-on: I understand and review everything I ship. Although the main
technologies are noted above, I'm flexible and I can handle other environments.
